# 已記錄流程

## A. 登入

1. 開啟 `https://intranet.ideas.iii.org.tw:8099/default.aspx`。
2. 系統導向 IDEAS Intra 單一簽入頁。
3. 使用者自行輸入 Email 帳號與密碼。
4. 登入成功後回到 `default.aspx`。

登入資料不記錄，也不在離線 fixture 中模擬真實驗證。

## B. 登入後首頁

1. 讀取注意事項。
2. 選擇店家分類：弍食穗／便當，或周胖子餃子館／麵類、餃子。
3. 對餐點的數量下拉選單選擇 `0` 到可用上限。
4. 可在對應的 `rmk{id}` 欄位填寫「餐點備註」。
5. 按下該店家的「放入購物車」。
6. 以購物車按鈕上的數字確認目前數量。

本次只觀察到首頁，尚未執行第 5 步，也沒有送出任何真實訂單。

## 自動化原則

- 餐點 ID 是純數字，CSS 不要寫成 `#545`；請使用 `[id="545"]`，或優先使用餐點的 ARIA label，例如 `get_by_role("combobox", name="水煮嫩雞胸數量")`。
- 備註欄位規則是 `[id="rmk545"]`，或使用 placeholder「餐點備註」搭配餐點區塊定位。
- 「放入購物車」目前是沒有穩定 ID 的 input button，建議以店家區塊或按鈕文字做相對定位。
- 不要重播 hidden `__VIEWSTATE`；每次由真實頁面產生。
- 任何「送出訂單」或付款動作都要保留人工確認。
